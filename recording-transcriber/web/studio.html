要幫哪支影片上字幕？

點一支影片先預覽、把不要的段落剪掉，再自動辨識、只修錯字不改寫，邊看影片邊微調，最後輸出影片，或直接上傳 YouTube。

    「影片」、「桌面」、「下載」（和設定的 iCloud 共用資料夾）裡沒有找到影片。

    標「iCloud」的影片放在 iCloud 共用資料夾的 studio，每台 Mac 都看得到；做好的檔案也會放在旁邊，一起同步。

    作者有上傳字幕就直接用，沒有才用 Soniox 辨識；再請 Claude 逐句翻成台灣繁中。下載的影片放在「影片／YouTube 下載」，只給自己看、做筆記用。

                設定

                YouTube 上傳

                每個人用自己的 Google Cloud 專案授權，工作室不會用到別人的帳號。第一次大約 15 分鐘，只要做一次：

                1. 到 Google Cloud Console 建一個專案，啟用「YouTube Data API v3」。
                2. 設定 OAuth 同意畫面（使用者類型選「外部」），再按「發布應用程式」改成正式版。停在「測試中」的話，授權 7 天就會過期。
                3. 建立 OAuth 用戶端 ID，應用程式類型選「電腦版應用程式」，下載 JSON 檔。
                4. 在下面選這個 JSON 檔，再按「連結 YouTube 頻道」。

                  還沒連結頻道。按下面的按鈕，會在瀏覽器打開 Google 的授權頁面；選要上傳的帳號或品牌頻道，按「允許」。

                  已經在瀏覽器打開 Google 的授權頁面，完成後這裡會自動出現頻道。沒有打開的話，按這裡打開。

                  講者名冊

                  用 Discord 分軌標講者時，帳號會換成這裡的名字，每場會議自動帶入。改名後要到那支影片按「重新標講者」，已經標好的字幕才會跟著換。

                  Discord 帳號字幕上的名字最近出現

                  還沒有記過任何人。用 Discord 分軌標過講者，或在下面先加新成員。

                  上傳到 YouTube

                  還沒有連結 YouTube 頻道。先到「設定」連結頻道，之後每次按一下就能上傳。

                  只想補上 CC 字幕的話，不用重傳影片：字幕會掛到 YouTube 上原本那支。
